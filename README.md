# Travel Atlas Demo

This repository contains a static multilingual tourism demo website showcasing sample countries, cities, and attractions.

## Open locally

Open `index.html` directly in a browser, or run a web server:

```bash
python3 -m http.server 8000
```

Then visit: `http://localhost:8000/`

## GitHub Pages

For GitHub Pages, set the source to `main` branch and `/docs` folder.

## Notes

This is a working demo created for quick viewing and demonstration. It includes:

- multilingual UI (Persian, English, French)
- country, city, and attraction cards
- images and descriptions
- search and filter
- anchor links to each country and city section
